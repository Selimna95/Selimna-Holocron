SELIMNA’S HOLOCRON · OUTIL DE COLLECTE

Récupérer les statistiques GAC

On va récupérer les classements publics SWGOH.GG depuis ton navigateur, car GitHub est bloqué par leur protection Cloudflare.

1

Préparer le favori (une seule fois)

Le lien ci-dessous contient le collecteur. Ne clique pas dessus. Il faut l'enregistrer comme favori.

Puis passe à l'étape suivante.

2

Créer le favori dans Edge

  1. Ouvre l'onglet SWGOH.GG — classement des personnages.
  2. Sur cet onglet, appuie sur Ctrl + D pour créer un favori.
  3. Dans la fenêtre, choisis Autres favoris puis clique sur Plus si Edge affiche les champs.
  4. Nom : Collecter GAC Holocron.
  5. Dans le champ URL, remplace toute l'adresse par le code copié à l'étape 1, puis enregistre.

Important : le code commence par javascript:. Il doit être dans le champ URL du favori, jamais dans la barre d'adresse ni dans une recherche Bing.

3

Lancer la collecte

  1. Reste sur la page SWGOH.GG où les classements sont visibles.
  2. Ouvre la barre des favoris avec Ctrl + Maj + B si elle est masquée.
  3. Clique sur le favori Collecter GAC Holocron que tu viens de créer.
  4. Une fenêtre Holocron apparaît en bas à droite et indique la progression. Attends le téléchargement de gac-browser-export.json.

Si la collecte est interrompue, reclique sur le favori : les vues déjà récupérées sont conservées pendant 12 heures.

4

Me transmettre le résultat

Glisse simplement le fichier gac-browser-export.json téléchargé dans cette conversation. Je vérifierai son contenu et l'intégrerai au dépôt. Tu n'as pas à modifier GitHub.

Aucun identifiant de compte n'est demandé. Les données absentes restent inconnues et ne sont jamais transformées en zéro.
