SELIMNA’S HOLOCRON · OUTIL DE COLLECTE

COLLECTEUR DE DONNÉES GAC

Ce petit outil lit les classements publics depuis ton navigateur, directement sur le domaine SWGOH.GG. Il évite le blocage Cloudflare rencontré par les collecteurs GitHub Actions.

1. Installer le favori

Fais glisser ce lien dans la barre des favoris de ton navigateur :

COLLECTER LES DONNÉES GAC

Si le glisser-déposer ne fonctionne pas, crée un favori manuellement et colle le code ci-dessous dans son champ URL.

2. Lancer la collecte

  1. Ouvre SWGOH.GG — Unit Tier List.
  2. Vérifie que les classements s’affichent normalement.
  3. Clique sur le favori « Collecter les données GAC ».
  4. Attends la fin des 30 vues. En cas d'interruption, relance le favori : les vues déjà collectées sont conservées pendant 12 heures. Le fichier gac-browser-export.json sera téléchargé.

3. Envoyer la base à Holocron

Le plus simple : joins le fichier gac-browser-export.json à la conversation ChatGPT qui t’aide à maintenir Holocron. Il pourra être vérifié et intégré au dépôt pour toi. Tu peux aussi faire l’import manuel :

  1. Ouvre le dépôt Selimna95/Selimna-Holocron.
  2. Ajoute le fichier téléchargé à la racine sous le nom exact gac-browser-export.json.
  3. Committe le fichier sur main. L’action GitHub tentera d’abord la source publique, puis importera cet export navigateur si le serveur est bloqué. Elle vérifiera les 20 vues personnages et 10 vues flottes avant de publier la base.

Les absences ne sont jamais converties en zéro. Les flottes ne couvrent que les compositions publiées par SWGOH.GG ; un vaisseau non observé reste inconnu.

Source : statistiques publiques de batailles GAC de première tentative, escouades complètes. L’outil n’accède à aucun compte privé et ne demande aucun identifiant.
